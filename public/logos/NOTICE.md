# 球队图标来源

本目录的 30 个 SVG 球队图标由 `react-nba-logos@1.1.3` 中的矢量组件转换为独立 SVG，未引入 React 运行时依赖。

- 原作者：Christopher Katsaras
- 原项目：https://github.com/ChrisKatsaras/react-nba-logos
- 分发包：https://www.npmjs.com/package/react-nba-logos/v/1.1.3
- 包声明许可证：ISC（来源包未附单独 LICENSE 文件）。

NBA 及各球队的名称和标志归各自权利人所有，图标仅用于识别比赛队伍；不表示球队或联盟对本项目的认可。图标为该来源包收录的版本，不保证与球队最新品牌改版一致。
